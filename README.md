# QA Testing Practice - Spring Boot

A simple Spring Boot application created for learning QA engineering.

## Tech Stack
- Java 17
- Spring Boot 3.3.5
- Spring Web
- Spring Data JPA
- H2 Database
- Maven
- Eclipse
- Postman

## API
POST `/users`
GET `/users`
GET `/users/{id}`

Start the application and test these APIs using Postman.
